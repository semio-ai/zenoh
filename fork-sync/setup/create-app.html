Create the semio-fork-sync GitHub App

This page sends the manifest below to GitHub, which registers the App under the semio-ai organization (not under your account). You need to be an owner of semio-ai.

  1. Click Continue to GitHub, check the name, and click Create GitHub App.
  2. GitHub redirects to github.com/semio-ai/fork-sync?code=…. Copy the value of code from the address bar and paste it into setup/bootstrap.sh when it asks. The code is valid for one hour and can be used once.

Permissions: Contents, Pull requests, Issues, Workflows (write); Metadata (read). No webhook, no events. Private to semio-ai.
